# 🛒 Projeto E-commerce com Python e Django

Loja virtual (e-commerce) desenvolvida do zero com **Python** e **Django**, com cadastro de produtos, carrinho de compras e fluxo de pedidos.

## 📸 Screenshots

![Página inicial do e-commerce](Site_de_vendas_Ecommerce.png)

## ✨ Funcionalidades

- Cadastro e listagem de produtos
- Carrinho de compras
- Fluxo de pedidos
- Organização do código seguindo boas práticas do Django

## 🛠️ Tecnologias utilizadas

- Python
- Django
- HTML e CSS
- SQLite (banco de dados padrão do Django)

## 🚀 Como executar o projeto

```bash
# Clone o repositório
git clone https://github.com/CarlosSergioOliveira1985/Ecommerce-Djando-2026.git

# Entre na pasta do projeto
cd Ecommerce-Djando-2026

# Crie e ative o ambiente virtual
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux/Mac

# Instale as dependências
pip install -r requirements.txt

# Aplique as migrações
python manage.py migrate

# Crie um superusuário (acesso ao /admin)
python manage.py createsuperuser

# Inicie o servidor
python manage.py runserver
```

Acesse em: http://127.0.0.1:8000
